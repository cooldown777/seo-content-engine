On September 24, 2026, Google added a new search type to Search Console: "Web: multimodal". It covers searches made with an image instead of typed words: Google Lens, Circle to Search on Android, image uploads to Google Search and "Search this image" in Chrome.

Start in Performance: set the search type to Web: multimodal and open the Pages tab. The same filter also works in the Generative AI performance report.

Then look at the images on those pages. Google calls alt text the most important image metadata, so describe the photo in a few specific words and skip keyword lists.

Use real img tags for key photos, because Google says it doesn't index CSS images. Descriptive filenames and nearby text can give extra context.
