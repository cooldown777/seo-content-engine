# Sources – 2026-10-03 (photo search / Web: multimodal, reel + carousel)

- Search Console reporting for web multimodal search, announced Thursday, September 24, 2026, "rolling out
  globally starting today"; covers Lens, Circle to Search on Android, image uploads to Google Search and the
  Chrome right-click "Search this image"; shown in the Search results performance report and the report for
  Generative AI features; use the new multimodal search type filter; "You will start seeing these metrics …
  if your site is receiving traffic from these queries" –
  https://developers.google.com/search/blog/2026/09/web-multimodal-in-sc
- Filter values "Web: text-based" and "Web: multimodal" ("when users search using images (such as with a
  smartphone camera)") – Performance report help: https://support.google.com/webmasters/answer/7576553
- Generative AI performance report (Search) has the same search type filter; rolled out to all websites
  worldwide as of August 31, 2026 – https://support.google.com/webmasters/answer/16984139
- "The most important attribute when it comes to providing more metadata for an image is the alt text";
  Google uses alt text "along with computer vision algorithms and the contents of the page"; avoid keyword
  stuffing in alt attributes; Google finds images in the src of an img element; "Google doesn't index CSS
  images"; extracts info from captions and nearby text; filenames give "very light clues" –
  Google image SEO best practices: https://developers.google.com/search/docs/appearance/google-images
- Examples (shoe page, black leather ankle boot, black-ankle-boot.jpg, CSS hero photo) are illustrative,
  not real sites or results.
- Not used: third-party claim that the Queries dimension is unavailable for multimodal data (not found in
  Google's own docs).
