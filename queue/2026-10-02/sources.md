# Sources – 2026-10-02 (internal linking, reel + carousel)

- "Google primarily finds pages through links from other pages it already crawled." –
  Google SEO Starter Guide: https://developers.google.com/search/docs/fundamentals/seo-starter-guide
- "Every page you care about should have a link from at least one other page on your site." –
  Google link best practices: https://developers.google.com/search/docs/crawling-indexing/links-crawlable
- "Generally, Google can only crawl your link if it's an a HTML element with an href attribute." – same page
- Anchor text should be "descriptive, reasonably concise, and relevant"; "click here" and "read more"
  listed as poor examples; tip to read only the anchor text out of context – same page
- Link in context to resources that help readers understand a page; "Don't chain up links next to
  each other" – same page
- Search Console Links report: "Top linked pages" from within your own site; select a URL to see
  which pages link to it – https://support.google.com/webmasters/answer/9049606
- Examples (trail running shoes, sizing guide, "View all" button) are illustrative, not real sites.
